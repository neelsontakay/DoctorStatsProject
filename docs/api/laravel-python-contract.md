# Laravel ↔ Python Statistical Service — API Contract

> **Status**: MVP implemented (analyze, status, results, Laravel callback).
> Both services must adhere to this contract. Changes require updating this
> document first, then both implementations.

## General

| Item | Value |
|---|---|
| Base URL (local) | `http://stats-service:8001` (Docker network) / `http://localhost:8001` (host) |
| Format | JSON request/response, UTF-8 |
| Authentication | Shared secret header `X-Service-Token` (optional in local dev when unset) |
| Versioning | Path prefix `/api/v1/...` |
| Interactive docs | `GET /docs` (Swagger UI, auto-generated by FastAPI) |

## Endpoints

## Laravel internal callbacks (stats-service → Laravel)

| Method | Path | Auth |
|---|---|---|
| `POST` | `/internal/v1/analysis-callback` | `X-Service-Token` |
| `GET` | `/internal/v1/data-files/{id}/download` | `X-Service-Token` |

Callback body mirrors the status fields plus optional `data_profile` and `tests[]` on completion.

### Resolved decisions

1. **Authentication**: `X-Service-Token` on both directions when configured.
2. **File transfer**: S3 pre-signed URLs in production; Laravel internal download URL for local disk.
3. **Progress reporting**: Callback webhooks (primary) plus `/status` polling on stats-service.
4. **Orchestrator**: Laravel queue submits the job; Python runs analysis in background tasks.
5. **Analysis ID**: Same as Laravel `job_id` (no mapping table).
